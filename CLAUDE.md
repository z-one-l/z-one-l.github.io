# Site notes for coding agents

This is a personal site built on al-folio v1.x. Layouts, includes and Sass come from the `al_folio_*` gems pinned in `Gemfile`; this repo only holds content, config and site-specific assets. Local `_layouts/`, `_includes/` or `_sass/` files override gem files. The only override is `assets/css/main.scss`, a copy of the gem's file with one added `@use "site"`, which loads the site's design layer `_sass/_site.scss` ("quiet academic": Source Serif 4 headings, Inter text, one deep-blue accent set through the theme's `--global-*` colour variables, light footer). The fonts are self-hosted in `assets/fonts/` and declared in `assets/css/fonts.css`, which `third_party_libraries.google_fonts` in `_config.yml` points to, so nothing loads from Google.

- Preview: `docker compose up -d` → http://localhost:8080/ (config edits restart Jekyll automatically).
- The home page (`_pages/about.md`) is a short academic profile: links row, bio, Research (IrisFlow card with `assets/img/irisflow/card-example.png`, drawn from the stored example below), Publications, Contact. A small script there forwards old IrisFlow anchors (`/#if-live`, `/#irisflow`, …) to `/irisflow/`.
- IrisFlow has its own page, `_pages/irisflow.md` (`/irisflow/`): the live demo first, then "How it works" with the four interactive panels as tabs (`assets/js/irisflow/tabs.js`; a hash naming a panel or a frozen-frame hook opens its tab), then the paper. The panels are plain JS/CSS in `assets/js/irisflow/irisflow.js` and `assets/css/irisflow.css`, opted in with `data-if-map`, `data-if-idea="joint"`, `data-if-pipeline` and `data-if-studio`. `_projects/irisflow.md` only redirects there.
- The live demo (`#if-live`, `assets/js/irisflow/live.js`, styles at the end of `irisflow.css`) runs the real model: it posts a JSON request to the `design` endpoint of the Hugging Face Space named in `data-if-live` (`lz-1/IrisFlow`, Gradio REST: `POST /gradio_api/call/design`, then read the SSE stream) and wakes the Space through `huggingface.co/api/spaces/...` when it sleeps. The Space runs on ZeroGPU (under 1 s of GPU time per request: 15 sampling steps, `adaptive_power` schedule, stochastic material and thickness flows); anonymous callers get only a couple of GPU runs, after which it answers on the CPU (up to 32 designs, about 2 s), and the response's `device` and `gpu_error` say which happened. Targets may lie anywhere in 380–2500 nm (the model was trained on 380–1400 nm). The band row (`bands (nm)`) picks up to 3 ranges for any source; the page resamples the target onto the paper's stitched 128-point grid (`bandGrid`, the same as `band_grid` in the Space and the benchmark's `_stitch_wavelength_grid`), while an unedited preset keeps its own grid. Materials whose measured n,k stop short of the target's longest wavelength are faded out and left out of the request (`NK_LIMIT`, mirroring `nk_max_nm` in the bundle's `materials.json`). Preset targets are in `assets/json/irisflow-presets.json` (the paper's application cases; the Space has its own copy); those with `beyond: true` are the eight wavelength-extension cases above 1400 nm, listed in their own group. The first preset (Solar AR) carries an `example`: the best 8 of one real 16-design run, which the panel shows, labelled, until the visitor changes the target or runs the model. The material list in `live.js` mirrors `materials.json` in the private bundle; the picker shows it one row per family (`FAMILIES`). Visitors can add up to 5 materials of their own from a CSV of wavelength (nm or µm), n, k ("+ n,k"); they are sent as `custom_materials` with the request, and both the page and the Space check that the data covers the target band, because the model reads n,k only at the target's wavelengths. The theme's CSP allows `connect-src https:` only, so to test against a Space app running locally open `http://localhost:8080/?if-space=http://127.0.0.1:7861` in a browser that bypasses the CSP (headless Chrome with `Page.setBypassCSP`).
- Panels must keep a constant height while they animate (text that changes is given a reserved height via `reserveHeight` / `reserveWidth`), so content below never jumps.
- The IrisFlow page includes a Notion-style line outline (`assets/js/outline.js`, `assets/css/outline.css`) built from the page title and the article's h2/h3; `data-toc` on a heading overrides its label. It hides below 1100px viewport width.
- `protect_email: true`: this theme version does not pass the home page's contact icons through `al_email_protect`, so `_pages/about.md` sets `social: false` and writes its email links itself through the `al_email_protect_html` filter; `socials_in_search: false` keeps a percent-encoded copy out of the search box. Built pages must never contain the address whole or a `mailto:`.
- Commits in this repo carry no AI co-author trailer (owner's request).
- `jekyll-terser` minifies JS under `assets/` and drops `console.*` calls in production builds.
- Site URL is the root of `https://z-one-l.github.io` (`baseurl` is empty). Always build links with `relative_url`.
